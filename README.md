# Mrunali Weds Niraj — Wedding Invitation

A responsive wedding invitation website designed for GitHub Pages.

## Features
- Mobile and desktop responsive
- Maroon animated opening curtains
- Pastel + purple + maroon wedding theme
- Scratch-to-reveal wedding date
- Falling flower petals after the date is revealed
- Haldi details for Mrunali and Niraj
- Wedding venue section
- No framework required

## Publish on GitHub Pages

1. Create a new GitHub repository, for example:
   `mrunali-niraj-wedding`

2. Upload these files to the repository root:
   - `index.html`
   - `style.css`
   - `script.js`

3. Open:
   **Repository → Settings → Pages**

4. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**

5. Save.

GitHub will provide a URL similar to:

`https://YOUR-USERNAME.github.io/mrunali-niraj-wedding/`

That URL can later be converted into a QR code for the printed wedding invitation.
